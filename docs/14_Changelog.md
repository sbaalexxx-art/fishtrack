# Purpose

This document records the history of AIFishMap.

Every release, sprint completion and important milestone must be recorded here.

The changelog reflects what was actually completed, not what was planned.

Each release should include:

- Version
- Date
- Sprint
- Summary
- Features
- Improvements
- Fixes
